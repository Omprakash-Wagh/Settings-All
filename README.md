# Settings All for Flow Launcher

A Flow Launcher plugin to do a deep search for all Windows Settings pages by scanning `SystemSettings.dll`.

## Features
- Deep search for all Windows settings pages.
- Access hidden or nested settings quickly.

## Installation
Type `pm install Settings All` in Flow Launcher, or download the latest release from the [Releases](https://github.com/Omprakash-Wagh/Settings-All/releases) page and extract it to your plugins folder.

## Requirements
- Flow Launcher
- Windows 10 or 11
- .NET 9.0 Desktop Runtime (usually included with Flow Launcher)

## Building from source
```bash
dotnet publish -c Release -o publish_output
```
